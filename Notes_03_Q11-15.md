## Q11. Meeting Rooms II (A) and Task Scheduler (B)

**Part A.** Given meeting time intervals `[start, end)`, return the minimum number of rooms required.

```
[[0,30],[5,10],[15,20]] -> 2
[[7,10],[2,4]]          -> 1
[[1,5],[5,8],[8,9]]     -> 1
```

**Part B.** `tasks` are letters, each takes one unit of time. Between two runs of the same task there must be at least `n` units of cooldown (idle or other tasks). Return the minimum total time.

```
tasks=["A","A","A","B","B","B"], n=2 -> 8
tasks=["A","A","A","B","B","B"], n=0 -> 6
tasks=["A","A","A","A","A","A","B","C","D","E","F","G"], n=2 -> 16
```

**Idea.** Rooms: sort starts and ends separately and sweep. A meeting that starts before the earliest end needs a new room, otherwise it reuses one. Tasks: the most frequent task forces a frame structure. The answer is `(maxFreq - 1) * (n + 1) + (number of tasks with maxFreq)`, but never less than the number of tasks.

```java
public static int minMeetingRooms(int[][] intervals) {
    int n = intervals.length;
    int[] starts = new int[n], ends = new int[n];
    for (int i = 0; i < n; i++) { starts[i] = intervals[i][0]; ends[i] = intervals[i][1]; }
    Arrays.sort(starts);
    Arrays.sort(ends);
    int rooms = 0, e = 0;
    for (int i = 0; i < n; i++) {
        if (starts[i] < ends[e]) rooms++;      // no room is free yet
        else e++;                              // reuse the room that just freed
    }
    return rooms;
}
// Approach 2: self
public static int minMeetingRooms(int[][] intervals){
    int result = 0;
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
    PriorityQueue<Integer> pq = new PriorityQueue<>(Integer::compareTo);
    pq.add(intervals[0][1]);
    result++;
    for (int i = 1; i < intervals.length; i++) {
        if(pq.peek() > intervals[i][0]){
            result++;
        } else {
            pq.poll();
        }
        pq.add(intervals[i][1]);
    }

    return result;
}

public static int leastInterval(char[] tasks, int n) {
    int[] freq = new int[26];
    for (char c : tasks) freq[c - 'A']++;
    int maxFreq = 0;
    for (int f : freq) maxFreq = Math.max(maxFreq, f);
    int countMax = 0;
    for (int f : freq) if (f == maxFreq) countMax++;
    return Math.max(tasks.length, (maxFreq - 1) * (n + 1) + countMax);
}
```

**Complexity.** Rooms: O(n log n). Scheduler: O(n).

## Q12. Minimum Cost to Connect Ropes (A) and Last Stone Weight (B)

**Part A.** Given rope lengths, you may join two ropes at a cost equal to the sum of their lengths. Return the minimum total cost to join them all into one.

```
[1,2,3,4,5] -> 33
[4,3,2,6]   -> 29
[5]         -> 0
```
**Part A.2** Relaxed: a join may use up to K ropes. Pad with zero-length ropes so the count works out.

```
ropes=[1,2,3,4,5], K=3 -> 21
    join 1+2+3 = 6 (cost 6), heap {4,5,6}; join 4+5+6 = 15 (cost 15); total 21

ropes=[1,2,3,4,5], K=2 -> 33        (same as Part A)

ropes=[1,2,3,4], K=3   -> -1        strict: (4-1) % (3-1) = 1, so it can't end in one rope
ropes=[1,2,3,4], K=3   -> 13        relaxed: pad one 0; join 0+1+2 = 3 (cost 3),
                                    heap {3,3,4}; join 10 (cost 10); total 13

ropes=[7], K=3         -> 0         already one rope
```

**Part B.** Each turn, smash the two heaviest stones. If they are equal both vanish, otherwise the heavier one is left with the difference. Return the weight of the last stone (0 if none).

```
[2,7,4,1,8,1] -> 1
[1]           -> 1
[3,3]         -> 0
```

**Idea.** Both are greedy with a heap. Ropes: always join the two **shortest**, because a rope joined early gets paid again for every later join. Stones: always take the two **heaviest** from a max-heap.

```java
public static long connectRopes(int[] ropes) {
    PriorityQueue<Long> pq = new PriorityQueue<>();
    for (int r : ropes) pq.offer((long) r);
    long cost = 0;
    while (pq.size() > 1) {
        long a = pq.poll(), b = pq.poll();
        cost += a + b;
        pq.offer(a + b);
    }
    return cost;
}

public static long connectRopesUpToK(int[] ropes, int K) {
    int n = ropes.length;
    if (n <= 1) return 0;
    if (K < 2) return -1;

    PriorityQueue<Long> pq = new PriorityQueue<>();
    for (int r : ropes) pq.offer((long) r);
    while ((pq.size() - 1) % (K - 1) != 0) pq.offer(0L);   // dummy ropes cost nothing

    long cost = 0;
    while (pq.size() > 1) {
        long joined = 0;
        for (int i = 0; i < K; i++) joined += pq.poll();
        cost += joined;
        pq.offer(joined);
    }
    return cost;
}

public static int lastStoneWeight(int[] stones) {
    PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());
    for (int s : stones) pq.offer(s);
    while (pq.size() > 1) {
        int y = pq.poll(), x = pq.poll();
        if (y != x) pq.offer(y - x);
    }
    return pq.isEmpty() ? 0 : pq.peek();
}
```

**Complexity.** O(n log n) time, O(n) space.

## Q13. Valid Parentheses (A) and Minimum Removals to Make Valid (B)

**Part A.** The string contains `()[]{}`. Return true if every bracket is closed by the same type in the correct order.

```
"()[]{}" -> true
"(]"     -> false
"([)]"   -> false
"{[]}"   -> true
```

**Part B.** The string contains letters and parentheses. Remove the minimum number of `(` or `)` so the result is valid, and return any valid string.

```
"lee(t(c)o)de)" -> "lee(t(c)o)de"
"a)b(c)d"       -> "ab(c)d"
"))(("          -> ""
```

**Idea.** A stack matches each closer to the latest opener. For Part B, store indices of unmatched `(` on the stack and mark unmatched `)` immediately. Whatever is left on the stack is also unmatched. Remove all marked indices.

```java
public static boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') {
            stack.push(c);
        } else {
            if (stack.isEmpty()) return false;
            char open = stack.pop();
            if ((c == ')' && open != '(') || (c == ']' && open != '[') || (c == '}' && open != '{'))
                return false;
        }
    }
    return stack.isEmpty();
}

public static String minRemoveToMakeValid(String s) {
    Set<Integer> remove = new HashSet<>();
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (c == '(') stack.push(i);
        else if (c == ')') {
            if (stack.isEmpty()) remove.add(i);
            else stack.pop();
        }
    }
    while (!stack.isEmpty()) remove.add(stack.pop());
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < s.length(); i++) if (!remove.contains(i)) sb.append(s.charAt(i));
    return sb.toString();
}
```

**Complexity.** O(n) time and space.

## Q14. Group Anagrams

**Part A.** Group the strings that are anagrams of each other (any group order). Use the sorted string as the key.

```
["eat","tea","tan","ate","nat","bat"] -> [["bat"],["nat","tan"],["ate","eat","tea"]]
[""]                                   -> [[""]]
["a"]                                  -> [["a"]]
```

**Part B.** Solve it with a character-count key instead of sorting (all lowercase letters).

**Idea.** Anagrams share a canonical form. The sorted string costs O(L log L) per word. A 26-count signature costs O(L).

```java
public static List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> groups = new HashMap<>();
    for (String s : strs) {
        char[] arr = s.toCharArray();
        Arrays.sort(arr);
        groups.computeIfAbsent(new String(arr), k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(groups.values());
}

public static List<List<String>> groupAnagramsCount(String[] strs) {
    Map<String, List<String>> groups = new HashMap<>();
    for (String s : strs) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;
        StringBuilder key = new StringBuilder();
        for (int c : count) key.append(c).append('#');   // separator avoids ambiguity
        groups.computeIfAbsent(key.toString(), k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(groups.values());
}
```

**Complexity.** Sorted key: O(n L log L). Count key: O(n L).

## Q15. Decode String (A) and Basic Calculator II (B)

**Part A.** Decode a string in the form `k[encoded]`, which repeats `encoded` exactly `k` times. Brackets can be nested.

```
"3[a]2[bc]"     -> "aaabcbc"
"3[a2[c]]"      -> "accaccacc"
"2[abc]3[cd]ef" -> "abcabccdcdcdef"
```

**Part B.** Evaluate an expression with non-negative integers and `+ - * /` (no parentheses). Integer division truncates toward zero.

```
"3+2*2"    -> 7
" 3/2 "    -> 1
" 3+5 / 2 " -> 5
```

**Idea.** Both use a stack. Decode string: when you see `[`, push the current count and the string built so far, then start fresh. On `]`, pop and repeat. Calculator: keep the last operator. `*` and `/` combine with the stack top immediately, while `+` and `-` push a signed number, and the answer is the stack sum.

```java
public static String decodeString(String s) {
    Deque<Integer> counts = new ArrayDeque<>();
    Deque<StringBuilder> prevs = new ArrayDeque<>();
    StringBuilder cur = new StringBuilder();
    int k = 0;
    for (char ch : s.toCharArray()) {
        if (Character.isDigit(ch)) {
            k = k * 10 + (ch - '0');
        } else if (ch == '[') {
            counts.push(k);
            prevs.push(cur);
            cur = new StringBuilder();
            k = 0;
        } else if (ch == ']') {
            StringBuilder prev = prevs.pop();
            int times = counts.pop();
            for (int i = 0; i < times; i++) prev.append(cur);
            cur = prev;
        } else {
            cur.append(ch);
        }
    }
    return cur.toString();
}

public static int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    char sign = '+';
    int num = 0;
    for (int i = 0; i < s.length(); i++) {
        char ch = s.charAt(i);
        if (Character.isDigit(ch)) num = num * 10 + (ch - '0');
        if ((!Character.isDigit(ch) && ch != ' ') || i == s.length() - 1) {
            if (sign == '+') stack.push(num);
            else if (sign == '-') stack.push(-num);
            else if (sign == '*') stack.push(stack.pop() * num);
            else if (sign == '/') stack.push(stack.pop() / num);
            sign = ch;
            num = 0;
        }
    }
    int sum = 0;
    for (int v : stack) sum += v;
    return sum;
}
```

**Complexity.** O(n) time and space (decoding is O(output length)).
